# Launchic

**Find opportunities. Launch smarter. Grow faster.**

Launchic is an AI growth operating system built around four V1 pillars:

1. **Business Brain** — capture the business, audience, positioning, and growth goal.
2. **Scout** — identify and rank actionable growth opportunities.
3. **Launchpad** — turn an opportunity into a focused launch plan and tasks.
4. **Meter** — measure launch activity and growth signals.

## Current MVP

The repository contains the initial Next.js App Router MVP shell, responsive UI, navigation, Business Brain form, opportunity discovery UI, launch builder, and Meter dashboard.

Current data is intentionally local/mock. No production database, authentication, billing, or AI provider is wired yet.
